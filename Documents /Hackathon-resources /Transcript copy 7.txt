Start by logging into your Falco DB cloud account. Then inside the instances window, hit create. Under the subscription plan panel, subscribe to the Fal DB enterprise plan to get started. Now you're ready to customize your instance. Differently from other plans, the enterprise plan allows you to select a public or private network. in the network connectivity section. You can also customize your instances deployment region type and other important parameters to your use case. Note that a custom network is available but must be created before creating this new database instance. The customer network you've set up before spinning up a new instance will appear in the customer network drop-down list here. In this configuration panel, you can also configure the size of the node instance as well as the instanc's name and admin user credentials. When you're done customizing your instance, click on the create button on the right to spin up the instance, which should take a couple of minutes. Lastly, we recommend keeping a copy and saving your instance ID. Once live, click on your instance name to display a comprehensive instance report that provides detailed information about your instance, including its key details, connectivity, nodes, and other relevant information, as well as your endpoints. Switch to the Falor DB browser and paste the endpoint you copied from the connectivity tab in the previous step. The Falore DB browser enables you to visualize your graph. Zooming in and right clicking on any node reveals its attributes panel, which you can consult or modify at any time. The menu on the right contains smart filters that helps you focus on specific groups of edges, expediting the exploration process. Additionally, you can click on history button to view past queries and their performance metrics such as total runtime. Use the first endpoint to connect to the database and the last one to query the Prometheus metrics. In the note tab, you can monitor the health of each node in the cluster and the audit logs tab provides a detailed audit trail of user actions that you may want to track.
