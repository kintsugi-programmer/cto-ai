Start by logging into your Falco DB cloud account. If you don't already have an account, you can sign one up by clicking the sign up button below. Now that you're in, click on the create button to spin up a new FalDB instance. You can see that you're subscribed to the free tier by default, and upgrading to another tier when you're ready is quite simple. Also, on this screen, you can tune the instance to your project. You can select the kind of subscription that you want, the cloud provider, as well as the region you'd like to store your project in. Next, you can use this panel to configure different aspects of your deployment, specifically its name, primary user, as well as a password. The summary of your deployment is displayed on the right. Now that your instance is live and running, click on its name to appear inside for a more detailed overview of it. You'll find your instances endpoint inside the connectivity tab. Copy it for easy access to it later. Next, click the connect button to enter the Falco DB browser to visualize, interact with, and modify your graph data. The username and password configured during the instance creation are already prepopulated. The default query the browser ran at launch displays the labels and relationships currently on record. The smart filter on the left allows you to toggle different aspects of the graph on and off. When zooming in on a node, you can rightclick it in order to bring up this node's editable attributes panel, which allows you to view or modify these attributes at any point in time. Now that you're all set up, you can view your instances audit logs back in the cloud control panel, as well as the Reddis data backup terms if those apply in your case. Lastly, stopping, modifying, or rebooting your instance can be easily done using the actions button on the right. Thanks for checking out FalDB's fully managed cloud offering. Many features normally reserved for enterprises in competing graph databases like multi-tenency are readily available to you even in the free tier. Whether you're building in the cyber security, agentic AI, or identity management spaces, you'll find our graph database will handle tough multihop queries with ease and at jaw-dropping speeds. If you've got any questions, we're right here to help you. Happy graphing.
